1 Configuração do Google

Informe o Client ID OAuth do seu projeto no Google Cloud (com a Google Photos Picker API habilitada). Ele fica salvo apenas neste navegador. Como obter?

  1. Acesse console.cloud.google.com e crie (ou selecione) um projeto.
  2. Em APIs e serviços → Biblioteca, habilite a Google Photos Picker API.
  3. Em APIs e serviços → Credenciais, crie um ID do cliente OAuth do tipo Aplicativo da Web.
  4. Adicione a origem desta página (ex.: http://localhost:8000) em Origens JavaScript autorizadas.
  5. Na Tela de consentimento OAuth, adicione seu e-mail como usuário de teste.
  6. Copie o Client ID e cole acima.

2 Google Fotos

Faça login com sua conta Google e selecione as fotos que deseja validar. Desde 2025 o Google só permite acesso via Picker: na janela que abrir, selecione as fotos (é possível selecionar todas) e confirme.

3 Apple (iCloud) Fotos

A Apple não oferece API pública para o iCloud Fotos, então a leitura é feita a partir de uma pasta local com suas fotos do iCloud. De onde vem essa pasta?

  • Windows: instale o iCloud para Windows e aponte para a pasta Fotos do iCloud.
  • macOS: no app Fotos, selecione tudo e use Arquivo → Exportar → Exportar original não modificado para uma pasta.
  • iCloud.com: baixe suas fotos (seleção + download) para uma pasta.
  • privacy.apple.com: solicite uma cópia dos seus dados de Fotos e extraia o ZIP.

Os arquivos não são enviados a lugar nenhum — apenas nome, tamanho e data (EXIF) são lidos, localmente.
